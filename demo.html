LeafLens

Offline crop-leaf health triage — not a diagnosis. Three classes: healthy, olive peacock spot (Spilocaea oleagina), olive bud mite damage (Aculus olearius).

Do not use this as a diagnosis, and never as a spray prescription. No pesticide dose is given here. If the result is uncertain or a disease is possible, check other leaves and ask an agronomist before spraying anything.

Try it (command line, offline once the model is downloaded)

cd ~/workspace/projects/leaflens
python3 predict.py <photo.jpg>
python3 predict.py <photo.jpg> --lang fr

If the top probability is below 0.60, the output is UNCERTAIN instead of a forced class.

Real example predictions (fine-tuned model, held-out test images)

  • aculus test photo → aculus_olearius, 0.999
  • healthy test photo → healthy, 1.000
  • peacock-spot test photo → olive_peacock_spot, 1.000

Full numbers: test accuracy 0.9607, macro-F1 0.9611 (n = 509, held-out). Frozen-backbone baseline: 0.8723. See RESULTS.md for the confusion matrix — the main error is peacock spot called healthy (10 of 219) — and for the limits: Denizli photos only, plain backgrounds, 3 classes only, no field accuracy claimed.
